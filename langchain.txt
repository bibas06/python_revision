Sequential chains
Some problems can be only be silved Sequentially....
consider a chatbot used to create a travel itinerary we need to tell to chatbot about destnations we receive 
suggestions on what to see on our trip and tell the model which activities to select to compile the itinerary
It is a sequential problem is it requires more than one user input, one to specify the destination
and another to select the activities.
In sequential chain the output from one chain becomes the input to another
destination_prompt=PromptTemplate(
    input_variables=['destination']'
    template='I am planning a trip to {destination}.Can you suggest some activitiesto do there?'
)
activities_prompt=PromptTemplate(
    input_variables=['activities'],
    template='I only have one day, so can you create a itinerary from your top three activities: {activities}.'
)
llm=ChatOpenAI(model='gpt-4o-mini',api_key=openai_api_key)                   We define our model and bgin the sequential chain
seq_chain=({'activities':destination_prompt | llm | StrOutputParser()}       We start by defining a dictionary that passes our destination_prompt template
   | activities_prompt                                                       to LLM and parses the output a string assigned as activities which is input for 
   | llm                                                                     activities_prompt which is passed to LLM generate the intenrary which is parsed as a string
   | StrOutputParser())

print(seq_chain.invoke({'destination':'Rome'}))

OpenAI offers two primary API interfaces, each with its own set of models:
Chat Completions API (chat.completions.create): This is the modern, recommended API. It uses a conversational format with system, user, and assistant messages.
gpt-4-turbo, gpt-4: Top-tier models for complex tasks.
gpt-3.5-turbo: The workhorse model, perfect for most tasks. Always prefer the latest version (e.g., gpt-3.5-turbo-0125).
Legacy Completions API (completions.create): This is the older API that your original code uses. It takes a single text prompt and returns a completion.
text-davinci-003: The most capable model in this family, but now deprecated and more expensive than gpt-3.5-turbo.
davinci, curie, babbage, ada: Even older, less capable base models.

A Few-Shot Prompt Template is a prompt that includes several examples (the "shots") of a task and its
desired output, followed by the actual task you want the model to perform. 
The model learns the pattern, format, and style from these examples and applies it to the new input.

from openai import OpenAI

client = OpenAI(api_key="your_api_key")

response = client.chat.completions.create(
    model="gpt-3.5-turbo",
    temperature=0,  # Low temperature for more deterministic, factual outputs
    messages=[
        {"role": "system", "content": "You are a helpful assistant that classifies sentiment."},
        {"role": "user", "content": "The product broke after two days of use."},
        {"role": "assistant", "content": "negative"},
        {"role": "user", "content": "It's okay, nothing special really."},
        {"role": "assistant", "content": "neutral"},
        {"role": "user", "content": "The package arrived early and everything was perfect!"},
        {"role": "assistant", "content": "positive"},
        {"role": "user", "content": "I absolutely loved the concert last night, the band was incredible!"}
    ]
)

print(response.choices[0].message.content)
# This will output: positive
